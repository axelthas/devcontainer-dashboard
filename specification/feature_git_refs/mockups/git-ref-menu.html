Design notes

  1. Same trigger, same place.

    The branch chip in the row stays. A press opens the menu; a second press closes it.

  2. Search first.

    The cursor starts in the search field. Every word must match, in any order: 42 term finds feat/42-terminal-engines. Arrow keys move, Enter checks out, Escape closes.

  3. Fetch and Pull.

    Fetch runs git fetch --all --prune. Pull runs git pull --ff-only and shows how far the branch is behind. Pull is off on a detached HEAD or without an upstream.

  4. Three sections, newest first.

    Local branches, remote branches, tags. Branches sort by tip commit date, tags by creation date. The right column shows the age.

  5. Remote checkout.

    A remote branch creates a local tracking branch. local means that the name exists locally; checkout then selects the local branch. upstream marks the upstream of the current branch.

  6. Outside press closes.

    A press anywhere outside the trigger and the menu closes it, also a press on the trigger of another row.
